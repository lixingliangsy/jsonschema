# JSONSchema — Feature pillars

## Core engine
- Turns a sample JSON object into JSON Schema draft 2020-12
- Marks required fields automatically
- Explains each validation rule in plain language

## Workflow & output
- API developers get a strict contract from a sample instead of hand-writing schema
- Drops into modern validators without version friction
- Documented rules for what the API should reject

## Trust & control
- Decision-support for schema design — not a security audit
- No fabricated compliance badges
- Demo mode without a live API key
